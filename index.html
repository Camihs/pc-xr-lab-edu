Explora el ecosistema del computador

Conceptos clave para orientar tu recorrido por el hardware.

GUÍA DE COMPONENTES
▦

Procesador (CPU)

Ejecuta instrucciones y coordina operaciones. Es una pieza central en el procesamiento de datos.

▤

Memoria RAM

Almacena temporalmente datos y programas que el equipo necesita utilizar rápidamente.

◈

Placa base

Conecta los componentes y permite la comunicación entre procesador, memoria y periféricos.

▣

Almacenamiento SSD

Conserva el sistema operativo, aplicaciones y archivos incluso cuando el computador está apagado.

▰

Tarjeta gráfica (GPU)

Procesa gráficos e imágenes. Es importante para visualización, diseño y simulaciones 3D.

⌁

Fuente de poder

Convierte y distribuye energía eléctrica para alimentar los componentes del computador.

▥

Sistema de refrigeración

Disipa el calor generado durante el funcionamiento y ayuda a mantener temperaturas adecuadas.

⌗

Periféricos

Dispositivos de entrada y salida que permiten interactuar con el sistema informático.
